# Reply Thread — «Нить ответа»

Тап по цитате ответа вытягивает из неё нить. Нить идёт по левому полю чата и привязывается к оригинальному
сообщению, пока список плавно скроллится к нему. В момент «привязки» — лёгкая вибрация и кольцо-пульс на оригинале,
затем нить гаснет. Работает и когда оригинал уже на экране, и когда до него нужно доскроллить.

## Файлы
- `TMessagesProj/src/main/java/org/telegram/ui/Components/ReplyThreadDrawer.java` — вся логика и отрисовка (не View, рисует поверх списка чата).
- `ChatActivity.java` — 4 точки интеграции (~20 строк):
  1. поле `replyThreadDrawer`;
  2. вызов `replyThreadDrawer.draw(canvas)` в конце `dispatchDraw` списка чата;
  3. `replyThreadDrawer.onScrolled(dy)` в скролл-листенере;
  4. `startReplyThread(cell, id)` в `didPressReplyMessage` (ветка «тот же чат»).

## Как устроено
Оба конца нити ищутся среди видимых ячеек на каждом кадре, поэтому нить «приклеена» к сообщениям даже во время
анимации быстрого скролла (RecyclerAnimationScrollHelper двигает ячейки через translation). Если сообщение ушло
за экран, конец нити уходит за край, а источник экстраполируется по `dy`. Анимация без аллокаций в `draw`.

## Статус
Фаза 1: нить + привязка. Фаза 2 (план): мини-карта цепочки реплаев в быстром скролле.
